🐾 Animal Poaching Detection Dashboard

A Flutter-based monitoring dashboard designed to help detect and monitor illegal animal poaching activities using real-time data, location tracking, and detection analytics.

🚀 Features

📍 Live Location Tracking

🐘 Animal Detection Monitoring

👤 Human Detection Counter

🔊 Gunshot Audio File Analysis

📊 Detection History Tracking

🌐 Web + Mobile Support (Flutter Multi-Platform)

🛠 Tech Stack

Frontend: Flutter (Dart)
APIs: HTTP REST APIs
Location Services: Geolocator
File Upload: File Picker + Multipart Upload
UI: Material UI + Google Fonts

⚙️ Installation
Prerequisites

Flutter SDK Installed

Android Studio / VS Code

Git Installed

Check Flutter Installation:

flutter doctor
Clone Repository
git clone https://github.com/ROGITH-KRISHNA-M/Wildeye-animal-poaching-dashboard.git
cd frontend
Install Dependencies
flutter pub get
Run Application
flutter run

For Web:

flutter run -d chrome
📡 API Configuration

Update API URLs inside:

lib/main.dart

Replace with your backend server endpoint.

📦 Build APK
flutter build apk
🧪 Testing
flutter test
